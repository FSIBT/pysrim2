# Citing pysrim2

If you use pysrim2 in published work, please cite the paper about the original
pysrim, on which pysrim2 is based:

> Ostrouchov, C., Zhang, Y., Weber, W. J. (2018). pysrim: Automation, Analysis, and
> Plotting of SRIM Calculations. *Journal of Open Source Software*, 3(28), 829.
> https://doi.org/10.21105/joss.00829

```bibtex
@article{ostrouchov2018pysrim,
  author  = {Ostrouchov, Christopher and Zhang, Yanwen and Weber, William J.},
  title   = {pysrim: Automation, Analysis, and Plotting of {SRIM} Calculations},
  journal = {Journal of Open Source Software},
  year    = {2018},
  volume  = {3},
  number  = {28},
  pages   = {829},
  doi     = {10.21105/joss.00829},
  url     = {https://doi.org/10.21105/joss.00829}
}
```

This paper describes the original pysrim, not pysrim2. pysrim2 continues that project
(see {doc}`changes-from-pysrim`), and there is no pysrim2 paper or DOI yet.

## Citing the software

[`CITATION.cff`](https://github.com/FSIBT/pysrim2/blob/main/CITATION.cff) in the
repository has the citation metadata in the Citation File Format. GitHub's "Cite this
repository" button on the [repository page](https://github.com/FSIBT/pysrim2) is built
from that file.

## Citing SRIM

pysrim2 runs SRIM, so please cite SRIM too:

> J. F. Ziegler, M. D. Ziegler, J. P. Biersack, "SRIM – The stopping and range of ions
> in matter (2010)", Nucl. Instrum. Methods Phys. Res. B 268 (2010) 1818–1823,
> https://doi.org/10.1016/j.nimb.2010.02.091

SRIM © SRIM.com (James F. Ziegler). See {doc}`installation` for its licence.
