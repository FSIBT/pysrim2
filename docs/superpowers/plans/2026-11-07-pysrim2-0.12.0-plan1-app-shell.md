# pysrim2 0.12.0, plan 1: app shell and setup — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `pysrim2 install app` adds the desktop app to an existing install, and `pysrim2 app` opens a Qt window that checks the installation, walks the user through setting up SRIM (native, wine or container), says in the status bar what is missing, and follows the system's dark/light mode.

**Architecture:** The install loop of `pysrim2 install` moves into `srim/installer/runner.py` so the CLI and the app run steps the same way. A new package `srim/app/` holds the app: Qt-free modules (`settings.py`, `routes.py`, `guidance.py`) that the CLI and tests can import without PySide6, and Qt modules (`theme.py`, `statusbar.py`, `workers.py`, `window.py`, `setup.py`, `main.py`) imported only by `pysrim2 app`. The doctor checks gain a `route` argument so the app can check the route the user chose. Plans 2 (geometry, beam, run settings) and 3 (running, progress, results, saving, recent runs) fill the tabs this plan creates.

**Tech Stack:** Python ≥ 3.11, PySide6-Essentials ≥ 6.8 (QtWidgets, `QStyleHints.colorScheme`), pytest-qt with the `offscreen` platform, the existing installer registry (`srim/installer/steps.py`).

**Spec:** `docs/superpowers/specs/2026-11-06-pysrim2-0.12.0-desktop-app-design.md` (goals 1, 2 and 12; "Decided by Arun"; the `[app]` and `pysrim2 install app` decisions of 2026-11-07).

## Global Constraints

- The app is the optional extra `app = ["PySide6-Essentials>=6.8", "matplotlib"]`. `[all]` stays `pysrim2[parquet,hdf5,plot,tui]` and does not include `app`. Runtime dependencies stay numpy, pyyaml and pandas.
- `import srim`, `srim.cli` and every command except `pysrim2 app` never import PySide6 (scripts, Slurm jobs, the container and headless servers have no Qt). Only the Qt modules listed above import it, and only `srim.cli._app` imports them, inside the function.
- The container image (`Dockerfile`) installs pysrim2 without `[app]`; it is not changed.
- AGENTS.md rules apply to the setup screens: wine only in pysrim2's private prefix; never run a command that needs admin rights without confirmation. The app goes further: it never runs a `needs_admin` step itself; it shows the commands for the user to run in a terminal.
- `pysrim2 install` keeps its output and exit codes byte for byte (`tests/test_cli.py` must pass unchanged).
- Docs URL: `https://pysrim2.readthedocs.io`. App settings: `<data dir>/app/settings.json` (`srim.paths.data_dir()`).
- Every user-visible change gets a CHANGELOG line under `## [Unreleased]`; conventional commit prefixes; commit with explicit paths (`git commit -- <paths>`).
- Qt tests live in `tests/app/`, run with `QT_QPA_PLATFORM=offscreen`, skip when PySide6 or pytest-qt is missing (`pytest.importorskip`), and every wait has a timeout (`qtbot.waitUntil(..., timeout=...)`).

## Review Focus

1. A machine without PySide6 or without a display: `import srim`, `pysrim2 doctor`, `pysrim2 install`, scans keep working and never load Qt; `pysrim2 app` prints one line saying to run `pysrim2 install app` and exits 1. (Task 2)
2. A broken `settings.json` (truncated, not JSON, unknown theme or route, wrong types): the app starts with defaults for the bad fields and never crashes. (Task 3)
3. A step that needs admin rights (Linux wine packages through `sudo`, Windows VB5 registration): the app never runs it (there is no terminal for a password prompt); it shows the exact commands to copy and a "Check again" button. (Task 5)
4. `pysrim2 install app` on a `uv tool` install that already has extras (e.g. `tui`): the extras are kept; when the command fails (e.g. Windows refuses to replace the running `pysrim2.exe`), the `[fail]` line says to run the printed command by hand. (Task 2)
5. Slow or stuck checks and installs (podman installed but not running, a long SRIM download): the window stays responsive (checks and installs run off the GUI thread), and the wizard cannot be cancelled or closed while a step runs. (Tasks 4 and 5)

**Interfaces:**
- Produces:
  - `INSTALL_ERRORS: tuple[type[BaseException], ...]` (same members as today).
  - `@dataclass RunOutcome`: `installed: list[str]`, `admin_skipped: list[tuple[str, list[str]]]` (step name, its commands; also the comment-only "cannot be installed automatically" steps), `failed: str | None = None` (the step name), `interrupted: bool = False`; property `exit_code -> int` (130 interrupted, 1 failed, 2 admin skipped, else 0).
  - `run_steps(steps: list[Step], *, dry_run: bool = False, yes: bool = False, confirm: Callable[[Step, list[str]], bool] | None = None, say: Callable[[str], None] = print, warn: Callable[[str], None] = <print to stderr>, admin_hint: str = "rerun with --yes or run:") -> RunOutcome`. It is today's loop of `_install` with `print` replaced by `say`/`warn`; `confirm` is called for an admin step when `yes` is false (None means "no", without asking); a `KeyboardInterrupt` in `confirm` or in a step prints the same `\n[skip] <name>: cancelled` line and returns `interrupted=True`. The `[skip] <name>: needs admin rights — <admin_hint>` line uses `admin_hint`.
- Consumes: `Step`, `plan` from `srim/installer/steps.py`.

**Interfaces:**
- Produces (`srim/installer/app.py`):

  - `install_kind(prefix: Path | None = None) -> str`: `"uv-tool"` if `<prefix>/uv-receipt.toml` exists (prefix defaults to `Path(sys.prefix)`), else `"editable"` if the `pysrim2` distribution's `direct_url.json` has `dir_info.editable` true, else `"pip"`.
  - `installed_extras(receipt: Path) -> set[str]`: the extras of the `pysrim2` entry in `[tool] requirements` of a uv receipt (`tomllib`); empty set when absent or unreadable.
  - `app_command(kind: str, version: str, extras: set[str] = frozenset(), python: str = sys.executable, uv: str | None = shutil.which("uv")) -> list[str]`:
    - `uv-tool`: `["uv", "tool", "install", "--reinstall", f"pysrim2[{','.join(sorted(extras | {'app'}))}]=={version}"]`
    - `pip` with `uv` found: `[uv, "pip", "install", "--python", python, f"pysrim2[app]=={version}"]`; without: `[python, "-m", "pip", "install", f"pysrim2[app]=={version}"]`
    - `editable`: `[]`
  - The `app` step: name `app`, summary `install the desktop app (PySide6, matplotlib) into this pysrim2 install`, `check=app_available`, `commands` = `[shlex.join(cmd)]`, or `["# in your pysrim2 checkout run: uv sync --extra app"]` for `editable` (the runner then reports it as not installable here); `run` = `subprocess.run(cmd, check=True, timeout=PACKAGE_TIMEOUT_SECONDS)`, and a `CalledProcessError`/`OSError` is re-raised as `AppInstallError(f"{exc}; run it yourself: {shlex.join(cmd)}")` (add `AppInstallError` to `INSTALL_ERRORS`).
- Produces (`srim/cli.py`): `pysrim2 app` → `_app(args) -> int`: without `app_available()`, prints `the desktop app is not installed; run: pysrim2 install app` to stderr and returns 1; otherwise `from srim.app.main import main as app_main` inside the function and returns `app_main([])`.

- Produces (`srim/app/routes.py`):
  - `ROUTES = ("native", "wine", "container")`; `ROUTE_LABELS = {"native": "Native TRIM.exe", "wine": "Wine (pysrim2's own wine prefix)", "container": "Container (Podman or Docker)"}`.
  - `available_routes(system: str) -> list[str]`: windows `["native", "container"]`; linux and macos `["wine", "container"]`.

- Produces (`srim/app/settings.py`):
  - `@dataclass AppSettings`: `route: str | None = None`, `theme: str = "system"` (one of `"system"`, `"light"`, `"dark"`).
  - `settings_path() -> Path` = `data_dir() / "app" / "settings.json"`.
  - `load_settings(path: Path | None = None) -> AppSettings`: missing file, unreadable file or not a JSON object → defaults; each field that is missing, of the wrong type or not an allowed value → its default; unknown keys ignored.
  - `save_settings(settings: AppSettings, path: Path | None = None) -> None`: creates the folder, writes a temp file next to it and `os.replace`s it.
- Produces (`srim/app/guidance.py`):
  - `@dataclass(frozen=True) Guidance`: `text: str`, `target: str | None` (what a click opens; this plan uses `"setup"`; plan 2 adds field targets).
  - `setup_guidance(checks: list[dict], route: str | None) -> list[Guidance]`: route None → `[Guidance("Choose how SRIM runs: open the setup", "setup")]`; else one `Guidance(f"{name}: {detail}. Fix: {fix}", "setup")` per failing check (`ok` false), in check order; all ok → `[]`.
- Produces (`srim/cli.py`): `collect_checks(route=None)`: None keeps today's rule; `"native"` and `"wine"` give the SRIM checks (plus `vb5` on Windows; plus the wine checks for `"wine"`, on macOS too); `"container"` marks the SRIM and wine checks `not needed (container route)` and adds the container checks. `pysrim2 doctor` keeps calling it without a route.
