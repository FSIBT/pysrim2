# pysrim2 0.11.0 docs overhaul and citation: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** New front page with a Python route and an agent route side by side, an example gallery whose pictures are made by committed scripts, a first-simulation page, an agent guide, a regenerated API reference, `CITATION.cff` pointing at the 2018 JOSS paper, every git author in `pyproject.toml` and `CITATION.cff`, and a shorter README.

**Architecture:** Docs stay Sphinx + furo + MyST; `sphinx-design` is added for the front-page cards and thumbnail grid. Gallery pictures are made by one small script per entry in `docs/gallery/`, driven by `docs/gallery/make.py`; the images are committed to `docs/gallery/images/` and the docs build never runs SRIM. The gallery page includes each script with `literalinclude`, so code and picture come from the same file.

**Tech Stack:** Sphinx, furo, myst-parser, sphinx-design (new, `docs` group), matplotlib (`plot` extra), Textual (`tui` extra, SVG screenshots), pytest.

**Spec:** `docs/superpowers/specs/2026-11-07-pysrim2-0.11.0-docs-overhaul-design.md`

## Global Constraints

- `uv run --group docs sphinx-build -W -b html docs <dir>` must pass (Read the Docs uses `fail_on_warning: true`). The docs build never runs SRIM, wine, Docker or a gallery script.
- Runtime dependencies stay numpy, pyyaml, pandas. Docs-only tools go in the `docs` dependency group.
- Python 3.11+. Conventional commits, one concern per commit. Every user-visible change adds a line under `## [Unreleased]` in `CHANGELOG.md`.
- `examples/scripts/boron_in_gold_on_silicon.py` stays byte-identical to `skills/pysrim2/examples/boron_in_gold_on_silicon.py`; do not edit either.
- The 0.8.0+ API is the one shown everywhere (`TRIM(...).run()`, `results.<output>.df`, `run.yaml`, `run_scan`, `run_beam`).
- Gallery images: each committed file under 300 KB. No SRIM binaries or large outputs committed.
- Canonical URLs: repository `https://github.com/FSIBT/pysrim2`, docs `https://pysrim2.readthedocs.io`. README images use `https://raw.githubusercontent.com/FSIBT/pysrim2/main/<path>`.
- Citation: Ostrouchov, C., Zhang, Y., Weber, W. J. (2018). pysrim: Automation, Analysis, and Plotting of SRIM Calculations. *Journal of Open Source Software*, 3(28), 829. https://doi.org/10.21105/joss.00829 — always with a note that it is the paper about the original pysrim. No Zenodo DOI.
- The agent reference case: 200 boron ions, 20 keV, 7 degrees, into 100 nm Au on Si, seed 12345; mean depth about 282 angstrom.
- `docs/paper/` is not touched.

## Review Focus

1. A docs build on a clean checkout (Read the Docs): any new page, extension, include path or image path that warns breaks the release. Each docs task runs `sphinx-build -W -E`, and Task 5 adds a CI `docs` job.
2. README images and links on PyPI/GitHub: raw URLs that point at files that do not exist on `main`. Task 8 adds a test that maps each `raw.githubusercontent.com/FSIBT/pysrim2/main/<path>` URL to a file in the repository.
3. `make.py` on a machine without SRIM (Arun's Mac, CI default job): it must skip the SRIM entries with one line each and exit 0; it exits 1 only when an attempted entry raised. Task 2 tests both.
4. Old links: `tutorial.html` and `source/srim.html` are linked from the old README on PyPI and from elsewhere. Task 7 keeps an orphan `tutorial` page that points to the new pages; Task 5 keeps `source/srim` as an orphan page that points to the API reference.
5. Authors drift: a new contributor added to one file but not the other, or a git author missing. Task 1 tests both lists equal and (when git history is available) that every author and co-author name is listed.

**Interfaces:**
- Produces, for every entry script `docs/gallery/<name>.py` (every `*.py` there except `make.py` and names starting with `_`):
  - `TITLE: str` (one line, shown by `--list`)
  - `NEEDS_SRIM: bool`
  - `OUTPUT: str` — the file name it writes, e.g. `"heatmap.png"` (`.png` or `.svg`)
  - `def make(outdir: pathlib.Path) -> pathlib.Path` — writes `outdir / OUTPUT` and returns that path. It must not write anything else into `outdir` (temporary SRIM runs go in a `tempfile.TemporaryDirectory`).
- `make.py` functions: `entries() -> list[str]` (sorted names), `load(name) -> module`, `srim_available() -> bool` (`(srim.paths.srim_dir() / "TRIM.exe").is_file()`), `main(argv=None) -> int`.
- CLI: `python docs/gallery/make.py [--list] [--out DIR] [name ...]`; default `--out` is `docs/gallery/images` next to `make.py`; `matplotlib.use("Agg")` before any entry is loaded; unknown names → message and exit 2. For each selected entry: SRIM entry without SRIM → print `skip <name>: needs SRIM (<srim_dir>/TRIM.exe is missing)`; otherwise print `<name>: <path>` or, on an exception, `FAILED <name>: <exception>` and continue. Exit 1 if any attempted entry failed, else 0. `--list` prints one line per entry: `<name>  [SRIM]` or `<name>` then two spaces and `TITLE`.
- Fixture paths are relative to the repository root, found from `Path(__file__).resolve().parents[2]`, so the scripts work from any working directory.
