# pysrim2 0.12.0, plan 2: geometry, beam and run-settings editors — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Geometry, Beam and Run settings tabs of `pysrim2 app` edit a complete run setup (target layers with elements, isotopes and materials; the ion and its 0.10.0 distributions; exact or binned mode; the TRIM settings), the status bar says what is still missing or wrong and jumps to the field, edits can be undone, and the setup opens from and saves to a `run.yaml`.

**Architecture:** The app edits one *document*: a plain dict in the layout of the `spec:` section of `run.yaml`, in which values may still be missing (`None`). Qt-free code in `srim/app/model.py` turns the document into a `RunSpec` through `RunSpec.from_dict`, so every check is the library's own and the `SpecError` key says which field to flag. A Qt `DocumentModel` holds the document, its undo history and its problems; the three editor tabs read from it and change it only through `DocumentModel.edit`. Isotope and compound data are new, generally useful library data (`srim/core/isotopes.py`, `srim/core/compounds.py`).

**Tech Stack:** Python ≥ 3.11, PySide6-Essentials ≥ 6.8 (QtWidgets, `QAbstractTableModel`), matplotlib's `backend_qtagg` for the distribution plots, pytest-qt on the `offscreen` platform; `periodictable` only once, to generate the committed isotope table.

**Spec:** `docs/superpowers/specs/2026-11-06-pysrim2-0.12.0-desktop-app-design.md` (goals 2, 3 and 4; "Calls made after the builder check": source of truth, run settings tab, isotopes, undo, settings and user data, depends on 0.10.0; "Left to the builder": thin-layer rule, isotope source, materials list, exact/binned default). Plan 1 (`docs/superpowers/plans/2026-11-07-pysrim2-0.12.0-plan1-app-shell.md`) is merged; this plan builds on its window, status bar and Qt-free/Qt split.

## Global Constraints

- Everything from plan 1's Global Constraints still holds: `import srim`, `srim.cli` and every command except `pysrim2 app` never import PySide6; Qt modules are imported only from `srim.app.main`/`window`; Qt tests live in `tests/app/`, skip without PySide6 or pytest-qt, use the offscreen platform and bounded waits.
- Qt-free modules added here: `srim/core/isotopes.py`, `srim/core/compounds.py`, `srim/app/model.py`, `srim/app/materials.py`, `srim/app/elements.py`, `srim/app/drawing.py`. Each task that adds one adds it to the import line of `tests/test_no_qt.py`.
- The app validates through the library only (`RunSpec.from_dict`, `check_beam`, `quantity_from_value`). It adds no physics rule of its own; the only app-level checks are "a value is missing".
- A setup saved by the app is a normal `run.yaml`: `RunSpec.from_yaml` reads it, and `TRIM.from_spec` on it writes the same `TRIM.IN` as the equivalent script. A spec opened and saved without edits keeps its `to_dict()` exactly.
- Settings keys are stored in the document only when they differ from `srim.spec.SETTINGS_SCHEMA` defaults; the `beam` key only when the beam is distributed (the library refuses `beam` otherwise).
- "Natural" means no `mass_amu` key: SRIM's default element mass from `srim/data/elements.yaml`, so results match scripted runs. An isotope is the element symbol with `mass_amu` set to the isotope's mass.
- The periodic table offers Z = 1 to 92 (SRIM's range).
- User materials live in `<data dir>/app/materials.json` (`srim.paths.data_dir()`), written atomically like `settings.json`; a broken file reads as no materials.
- Every user-visible change gets a CHANGELOG line under `## [Unreleased]`; conventional commit prefixes; commit with explicit paths (`git commit -- <paths>`). Wait for every command you start to finish before reporting.

## Review Focus

1. A run.yaml written by hand or by the CLI that uses things the editors do not offer (calculation 4–7, a `fixed` shape, an inline histogram with `edges`/`counts`, `settings.plot_mode`, element binding energies, a gas layer): opening and saving it without edits keeps `to_dict()` identical. (Task 3)
2. Half-typed or nonsense numbers in table cells and distribution fields (empty, `-1`, `abc`, `1e400`, `1,5`): nothing crashes; an unparsable entry is refused and the old value stays; an empty one becomes "missing" and the status bar says so. (Tasks 5 and 7)
3. A very thin layer next to a very thick one (10 nm on 1 cm), more layers than fit at the minimum width, and no layers at all: the drawing never divides by zero and every layer stays visible and clickable. (Task 6)
4. A histogram file that is broken (one row, decreasing edges, not numbers) or that later moves: loading shows the library's message and leaves the setup unchanged; saving copies the file next to `run.yaml` so the setup keeps working when the folder moves. (Tasks 3 and 7)
5. New, Open or Quit with unsaved edits asks before discarding; Undo after Open never returns to the previous document. (Task 3)

### Task 2: The document, its problems and its history (Qt-free)

**Files:**
- Create: `srim/app/model.py`, `srim/app/materials.py`
- Modify: `srim/app/guidance.py` (`Guidance` gains `blocking: bool = True`), `tests/test_no_qt.py`
- Test: `tests/app/test_model.py`, `tests/app/test_materials.py` (both Qt-free)

**Interfaces:**
- Consumes: `RunSpec.from_dict`, `RunSpec.to_dict`, `SpecError`, `SETTINGS_SCHEMA` (`srim/spec.py`); `Guidance` (`srim/app/guidance.py`).
- Produces (`srim/app/model.py`):
  - `UNITS = {"Å": 0.1, "nm": 1.0, "µm": 1e3, "mm": 1e6}` (nm per unit); `best_unit(thickness_nm: float) -> str` (`≥ 1e6` → mm, `≥ 1e3` → µm, `≥ 1` → nm, else Å).
  - `new_document() -> dict` = `{"version": 1, "ion": {"symbol": None, "energy_keV": None, "angle_deg": 0.0}, "number_ions": 1000, "calculation": 1, "seed": 0, "settings": {}, "target": []}`.
  - `new_layer() -> dict` = `{"name": "", "thickness_nm": None, "density_g_cm3": None, "phase": 0, "elements": [], "_unit": "nm"}`; `new_element(symbol: str, mass_amu: float | None = None) -> dict` (stoich 1.0, displacement 25.0, lattice 0.0, surface 3.0; `mass_amu` key only when given).
  - Keys starting with `_` are app-only (the layer's display unit) and never reach the spec.
  - `clean(doc: dict) -> dict`: drops `_` keys; drops `name` when `""`, `mass_amu` when None, `azimuth_deg`/`position` when None; drops `beam` when the beam is not distributed; when distributed and there is no `beam` key and `default_beam_mode(doc)[0] == "binned"`, adds `{"mode": "binned"}`.
  - `to_spec(doc: dict, base_dir=None) -> RunSpec` = `RunSpec.from_dict(clean(doc), base_dir=base_dir)` (raises `SpecError`).
  - `from_spec(spec: RunSpec) -> dict` = `spec.to_dict()` with `_unit = best_unit(thickness)` on each layer.
  - `is_distributed(doc) -> bool` (a beam value is a mapping, or azimuth/position is set).
  - `default_beam_mode(doc) -> tuple[str, str]`: `("binned", BINNED_AUTO)` when `calculation` is not 1 or 2, else `("exact", EXACT_TEXT)`. Texts: `EXACT_TEXT = "Exact: each ion gets its own energy, angle and position from the distributions (TRIM.DAT)."`, `BINNED_TEXT = "Binned: the beam is split into bins and SRIM runs once per bin."`, `BINNED_AUTO = "Automatic chose binned because the monolayer calculation cannot read TRIM.DAT."`
  - `target_for_key(key: str) -> str | None` (strips a leading `spec.`): `ion.symbol`/`ion.mass_amu` → `beam/ion`; `ion.energy_keV…`, `ion.angle_deg…`, `ion.azimuth_deg…` → `beam/<name>`; `ion.position.<y_nm|z_nm|depth_nm>…` → `beam/<name>`, `ion.position` → `beam/y_nm`; `number_ions` → `beam/number_ions`; `beam…` → `beam/mode`; `target[i].thickness_nm` → `geometry/i/thickness`, `.density_g_cm3` → `geometry/i/density`, `.name` → `geometry/i/name`, `.phase` → `geometry/i/phase`, `.elements…` → `geometry/i/elements`; `target` → `geometry`; `settings.<k>` → `settings/<k>`; `calculation` → `settings/calculation`; `seed` → `settings/seed`; anything else → None. The key is the leading dotted name of the `SpecError` message (regex `^[A-Za-z_]+(\[\d+\])?(\.[A-Za-z_]+(\[\d+\])?)*`).
  - `problems(doc: dict, base_dir=None) -> list[Guidance]`: first the missing values, in this order and with this text (`<label>` is the layer name, else its symbols joined by `+`, else `new layer`; `<n>` is the 1-based row):
    - no ion symbol → `"Choose the ion: pick an element on the Beam tab"`, `beam/ion`
    - no energy → `"Enter the ion energy on the Beam tab"`, `beam/energy_keV`
    - `number_ions` None → `"Enter the number of ions on the Beam tab"`, `beam/number_ions`
    - no layers → `"Add a target layer on the Geometry tab"`, `geometry`
    - per layer: `"Layer <n> (<label>): add at least one element"` (`elements`), `"…: enter the amount of <symbol>"` (`elements`), `"…: enter the density"` (`density`), `"…: enter the thickness"` (`thickness`)
    - If anything is missing, return those. Otherwise call `to_spec` under `warnings.catch_warnings(record=True)`: a `SpecError` gives one `Guidance(str(error), target_for_key(...))`; each `UserWarning` gives `Guidance(str(warning), "beam/mode", blocking=False)` after it.
  - `History(limit: int = 200)`: `push(doc)` stores a deep copy of the state *before* an edit and clears redo; `undo(current) -> dict | None`; `redo(current) -> dict | None`; `can_undo`, `can_redo`; `clear()`; `mark_saved(current: dict)` and `is_modified(current: dict) -> bool` (compares with the state given to `mark_saved`, by `clean(...)` equality).
  - `prepare_for_save(doc: dict, folder: Path) -> tuple[dict, list[tuple[Path, Path]]]`: for each histogram `file` that is not already inside `folder`, the copy goes to `folder / "beam" / <file name>` (a different file of the same name gets `-2`, `-3`, … before the suffix) and the returned document refers to it as `beam/<name>`; returns the copies to make. A relative `file` is resolved against the document's previous folder by the caller (pass absolute paths).
- Produces (`srim/app/materials.py`): `UserMaterial(name: str, density_g_cm3: float, phase: int, elements: list[dict])` (elements as `new_element` dicts, isotopes kept); `materials_path() -> Path` (`<data dir>/app/materials.json`); `load_user_materials(path=None) -> list[UserMaterial]` (broken file or entry → skipped); `save_user_material(material, path=None)` (replaces one of the same name; atomic write); `delete_user_material(name, path=None)`.
