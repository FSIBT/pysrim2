# pysrim2 0.7.0 — Installer, Container and Real-SRIM Tests Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `uv tool install pysrim2` → `pysrim2 install` sets up SRIM (native Windows or Linux + wine) or the container, `pysrim2 doctor` reports status, `ghcr.io/fsibt/pysrim2` runs everything inside a container with `/data` mounted, real TRIM/SR runs are tested in CI, and a first agent skill ships and installs — released as 0.7.0.

**Architecture:** A small, dependency-free installer package `srim/installer/` built from *steps* (detect → plan → run), driven by an argparse CLI `srim/cli.py`. SRIM comes from our GitHub Release asset (checksum-pinned). Paths resolve through one module `srim/paths.py`, which `TRIM.run`/`SR.run` use by default. The Dockerfile reuses the spike recipe (Debian trixie, Debian wine 10, VB5 DLLs extracted from `msvbvm50.exe`).

**Tech Stack:** Python 3.11–3.15 stdlib (argparse, urllib, hashlib, zipfile, shutil, subprocess), uv, Docker/Podman, GitHub Actions + GHCR, wine 10 (Debian), xvfb.

**Spec:** `docs/superpowers/specs/2026-11-03-pysrim2-design.md` (sections Container, Packaging & tooling → Local install, Platform findings, Agent support, Release roadmap)

## Global Constraints

- Distribution `pysrim2`, import `srim`, Python ≥ 3.11; **no new runtime dependencies** (stdlib only for installer/CLI).
- SRIM is never shipped in the PyPI package or committed to git. Sources, in order: `https://github.com/FSIBT/pysrim2/releases/download/srim-2013/srim.2013.zip`, then `https://gitlab.com/costrouc/pysrim/-/raw/master/assets/srim.2013.zip`; SHA-256 `f425c4715d5a849c1f521a8fc14aff58d41066fa4ca773546690a220ff3acecf`, size 13768612. A mismatch is a hard error.
- Ziegler's notice (`srim/Data/LEGAL.rtf` from the zip) is kept next to every installed copy and in the image at `/opt/srim/Data/LEGAL.rtf`; docs and CLI output state "SRIM © James F. Ziegler — free for non-commercial use only".
- Nothing that needs admin rights runs without explicit confirmation (`--yes` or interactive `y`); `--dry-run` never changes anything and prints every step with its exact commands.
- Container: `linux/amd64` only; `ghcr.io/fsibt/pysrim2`; tags `vX.Y.Z`, `X.Y`, `latest` on release, `main` on pushes to main; non-root user; `/data` is the working directory.
- macOS native SRIM is not supported (container only); Docker Desktop is never installed by us — runtime installs default to Podman.
- Fork-commit and commit rules from Plan 1 still apply (small logical commits, CHANGELOG line under `[Unreleased]` per user-visible change).
- Work on `main`; CI (17 checks) must stay green; controller pushes after each reviewed task.

## Review Focus

1. Interrupted or corrupted SRIM download (partial file, wrong hash, both sources down) — must leave no half-installed directory and tell the user what failed and where to download manually. (Task 4)
2. `pysrim2 install` re-run on an already set-up machine — must be idempotent: report "already installed" per step, change nothing. (Tasks 4–7)
3. Paths with spaces (e.g. `C:\Users\Jane Doe\...`, SRIM's own `SRIM Outputs` folder) — install and runs must work. (Tasks 3, 4, 8)
4. No container runtime and no wine on Linux — `doctor` and `install --dry-run` must show the exact commands for this distro instead of failing. (Tasks 6, 7)
5. Existing pysrim users with SRIM in `/tmp/srim` — `TRIM(...).run()` with no argument must keep working. (Task 3)

### Task 6: Install steps, `pysrim2 install` and `pysrim2 doctor`

**Files:** Create `srim/installer/steps.py`, `srim/cli.py`; Modify `pyproject.toml` (`[project.scripts] pysrim2 = "srim.cli:main"`); Test `tests/installer/test_steps.py`, `tests/test_cli.py`

**Interfaces:** Produces
- `@dataclass Step(name: str, summary: str, check: Callable[[], bool], commands: Callable[[], list[str]], run: Callable[[], None], needs_admin: bool = False)`.
- `plan(components: Sequence[str]) -> list[Step]`, components: `srim`, `wine` (Linux only), `image`, `runtime`, `skill`; default set by platform: Windows → `srim, skill`; Linux with wine or none of (docker, podman) → `wine, srim, skill`; Linux/macOS with docker or podman and no wine → `image, skill`; macOS without a runtime → `runtime` shown as "needed" but not run without `--yes`.
- CLI: `pysrim2 install [COMPONENT ...] [--dry-run] [--yes] [--agent claude|all] [--scope user|project]`, `pysrim2 doctor [--json]`, `pysrim2 --version`. Exit code 0 when everything requested is installed, 1 on failure, 2 when admin steps were skipped.
- `doctor` checks: Python, pysrim2 version, SRIM dir + TRIM.exe + LEGAL notice, wine/xvfb-run/extractor/prefix (Linux), docker/podman + image present, skill installed per agent; `--json` prints `{"checks": [{"name", "ok", "detail", "fix"}]}`.
